## PROJECT TITLE: GUI Input
GUI Input is a small Java application that uses pop-up dialog boxes instead of the console to talk to the user. It asks for the user's name and age, greets them, and works out how old they will be in five years and how old they are now from their year of birth.

## FEATURES
### Greeting
- Asks for the user's name in an input dialog.
- Greets the user by name in a message dialog.

### Age calculations
- Asks for the user's age and tells them how old they will be in 5 years.
- Asks for the user's year of birth and works out their current age by subtracting the year of birth from the current year (2026).

## PROJECT STRUCTURE
GUI_Input: Main class and the only class. Shows the input and message dialogs and does the age calculations.

## TECHNOLOGIES USED
-Netbeans (Maven)
- Java
- Java Swing (`JOptionPane`) for the dialog boxes

## How to run
1. Open the project in NetBeans 
2. Run `GUI_Input`.
3. Type your answer into each dialog box and click OK to move to the next one.
